====================================================================
  راهنمای نصب سرویس چاپ صندوق گاتان (ویندوز ۱۰ + فیش‌پرینتر Sewoo 100)
====================================================================

پیش‌نیاز روی سیستم صندوق (فقط یک‌بار):
1. درایور فیش‌پرینتر Sewoo 100 روی ویندوز ۱۰ نصب و با کابل USB متصل باشد.
2. برنامه Node.js نسخه LTS (18 یا بالاتر) روی ویندوز ۱۰ نصب باشد:
   https://nodejs.org

مراحل نصب (کمتر از ۲ دقیقه):
1. این پوشه را در یک مسیر ثابت روی سیستم صندوق (مثلاً C:\GatanPrintAgent) قرار دهید.
2. وارد سامانه ERP گاتان شوید -> بخش «مشتریان» -> دکمه «صف چاپ صندوق» -> تب «نصب سرویس صندوق».
3. روی دکمه «تولید کلید امنیتی جدید» کلیک کنید و فایل config.json آماده را دانلود و در همین پوشه (کنار agent.mjs) قرار دهید.
   (یا فایل config.example.json را به config.json تغییر نام داده و serverUrl و apiKey را داخل آن وارد کنید.)
4. روی فایل test-print.bat دوبار کلیک کنید تا یک فیش تست ۷۲ میلی‌متری روی Sewoo 100 چاپ شود.
   - اگر پرینتر به‌صورت خودکار تشخیص داده نشد، با دستور `node agent.mjs --list-printers` نام دقیق چاپگر در ویندوز را ببینید و در فیلد "printerName" فایل config.json قرار دهید.
5. روی فایل install-service.bat کلیک راست کرده و Run as Administrator بزنید (یا دوبار کلیک کنید).
   - از این پس سرویس به‌صورت خودکار و مخفی با روشن شدن ویندوز اجرا می‌شود و وضعیت «صندوق آنلاین» در ERP سبز خواهد شد.

برای حذف سرویس:
روی uninstall-service.bat دوبار کلیک کنید.
